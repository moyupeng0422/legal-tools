# 漏检案例库

> 记录实战中发现的漏检/误报案例，是经验提炼的原始素材。**只追加，不删除**。
> 条目达到一定数量（≥5 条同模块）或规则明确后，提炼进 references/*.md 或 rules/*.py，并回 LESSONS.md 标 `[已固化]`。

## 条目格式

```
### YYYY-MM-DD-NN [模块] 一句话标题
- **原文片段**：文书中的实际文本（可脱敏）
- **应报 Issue**：issue_type / severity / action / 建议内容
- **漏检原因**：规则缺失 / 正则覆盖不到 / AI 语义判断遗漏 / 其他
- **处置**：→ 已固化到 references/05-legal-terms.md「易混术语」节 / 待观察
```
