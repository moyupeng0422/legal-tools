# M8 格式规范

## 检查逻辑

1. 从实体索引中提取案号、法院名称
2. 扫描全文检查序号连续性
3. 检查称谓一致性

## 信号模式

### 案号格式

> 案号年份括号规范为**全角**（2026-09-08 缺陷二修复同步：旧表示例自身用半角，属示范自错）。

| 正确格式 | 常见错误 | 严重等级 |
|---------|---------|---------|
| （2025）浙01民初123号 | （2025）浙01民初第123号 | 严重 |
| | （2025）浙01民初字第123号 | 严重 |
| | 2025浙01民初123号（缺括号） | 严重 |
| | (2025)浙01民初123号（半角括号） | 严重 |
| | （2025浙01民初123号（不配对） | 严重 |

### 法院名称

| 场景 | 正确 | 常见错误 | 严重等级 |
|------|------|---------|---------|
| 起诉状首部 | 浙江省杭州市中级人民法院 | 杭州市中级人民法院（缺省级） | 严重 |
| 起诉状首部 | 浙江省杭州市中级人民法院 | 杭州中院 | 严重 |
| 正文引用 | 杭州市中级人民法院 | 杭州中院（起诉状中不允许缩写） | 一般 |

### 序号连续性

| 信号 | 说明 | 严重等级 |
|------|------|---------|
| 中文数字序号跳号 | "一、""二、""四、"（缺"三"） | 严重 |
| 阿拉伯数字序号跳号 | "1.""2.""4."（缺"3"） | 严重 |
| 证据编号不连续 | "证据一""证据二""证据四" | 严重 |

### 称谓一致性

| 信号 | 说明 | 严重等级 |
|------|------|---------|
| 当事人指代不统一 | 全文中"原告""申请人""我方"混用，未定义简称 | 一般 |
| 法院指代不统一 | "本院""贵院""法院"混用 | 一般 |

## 典型案例

**案例 1：案号格式错误**

> 案号：（2025）浙01民初第123号

- **问题**: 案号中不应有"第"字，正确格式为"（2025）浙01民初123号"
- **严重等级**: 严重
- **建议**: 删除"第"字

**案例 2：序号跳号**

> 一、被告立即停止侵害原告专利权的行为；
> 二、被告赔偿原告经济损失人民币100,000元；
> 四、被告承担本案全部诉讼费用。

- **问题**: 序号从"二"直接跳到"四"，缺少"三"
- **严重等级**: 严重
- **建议**: 核实是否遗漏第三项诉讼请求

## 误报控制

- 以下情况不算格式错误：
  - 正文中的合理缩写（如"本院"代指受诉法院，属于正式法律文书规范用语）
  - 中文数字和阿拉伯数字混合使用（如"第一百二十三条"和"§123"混用是正常的）
  - 证据编号与清单编号不匹配但有合理解释（如部分证据当庭提交，未在起诉状中列明）
  - 不同章节使用独立的序号系统（如事实部分用"一、二、三"，理由部分重新从"一"开始）
