# 输出格式指南

## 报告结构

校对报告严格按以下结构输出：

1. **标题行**：`# 文书校对报告`
2. **概要信息**：文件名 + 检查模块 + 发现统计
3. **问题清单**：按致命 → 严重 → 一般排列，每条包含编号、位置、原文、问题、建议
4. **模块摘要表**：各模块命中统计
5. **免责声明**

## 问题条目格式

每条问题必须包含以下字段：

```markdown
#### P[编号] [模块标签] [位置]

> [原文摘录，保留足够上下文以理解问题]

- **问题**: [一句话描述问题是什么]
- **建议**: [一句话描述如何修改]
```

附加字段（按需）：
- `**依据**`: 当问题涉及外部数据源时标注来源
- `**计算**`: 当问题是金额计算错误时，展示计算过程

## 位置标注规范

| 标注方式 | 适用场景 | 示例 |
|---------|---------|------|
| §N | 标注段落编号 | §3 |
| §N-M | 标注段落内的具体位置 | §3-第2行 |
| 全文 | 问题贯穿全文 | 全文 |

## 模块标签

问题编号后使用方括号标注来源模块：

| 标签 | 模块 |
|------|------|
| M1 | 模板残留 |
| M2 | 全文一致性 |
| M3 | 法条校验 |
| M4 | 金额计算 |
| M5 | 术语/错别字 |
| M6 | 日期逻辑 |
| M7 | 交叉引用 |
| M8 | 格式规范 |

同一问题被多模块命中时，合并显示：`[M2, M8]`

## 特殊场景处理

### 无问题发现

如全文未发现任何问题，输出：

```markdown
**发现**: 致命 0 / 严重 0 / 一般 0

未发现需要修改的问题。
```

### 仅一般问题

如仅发现一般问题，无致命和严重问题，输出：

```markdown
**发现**: 致命 0 / 严重 0 / 一般 [N]

未发现致命或严重问题。以下一般问题供参考修改。
```

### 致命问题阻断

如发现致命问题，在问题清单最前面醒目标注：

```markdown
⚠️ 发现致命问题，建议修改后再发出。
```

## 输出文件命名

当 `report_format: file` 时，输出文件命名：
- 文件名：`校对报告_[原文件名].md`
- 存放位置：与原文件相同目录
