# M1 模板残留检测

## 检查逻辑

1. 从实体索引中提取所有当事人名称、案号、日期、金额、法院名称
2. 对每个实体，检查是否存在"上下文语义不匹配"的情况：
   - 当事人名称是否与本案案号/法院管辖范围匹配
   - 日期是否与案件时间线匹配（如起诉状写 2025 年案件但引用 2020 年合同日期且未说明关联）
   - 金额是否与案件标的额量级匹配
3. 检查是否存在"仅出现一次且位置异常"的实体（如某当事人名只在事实描述中出现一次，不在当事人列表中）
4. 检查页眉/页脚/文件属性中是否包含旧案件信息

## 信号模式

以下特征标记为"疑似模板残留"：

| 信号 | 说明 | 置信度 |
|------|------|--------|
| 当事人名称同时出现在当事人列表和事实描述中，但事实描述中的版本与当事人列表不同 | 典型替换遗漏 | 高 |
| 日期与案件案号年份不匹配 | 如案号 (2025) 但文中出现 2021 年日期作为关键日期 | 高 |
| 金额在文中仅出现一次，且与其他金额无计算关系 | 可能是旧合同金额未替换 | 中 |
| 存在其他常见当事人名称的字样片段（如另一律所名称、另一客户名称） | 可能是从旧文件复制时带入 | 中 |
| 文中有"于 XXXX 年签订"但该日期与本案无任何逻辑关联 | 遗留的旧事实描述 | 中 |

## 典型案例

**案例 1：当事人名称替换遗漏**

> 原告深圳腾讯计算机系统有限公司（以下简称"腾讯公司"）与被告北京字节跳动科技有限公司（以下简称"字节公司"），因侵害发明专利权纠纷一案...
>
> 原告深圳腾讯计算机科技有限公司于2023年5月10日向国家知识产权局申请了名称为"XXX"的发明专利...

- **问题**: 事实段中"深圳腾讯计算机科技有限公司"（少"市"字）与首部"深圳市腾讯计算机系统有限公司"不一致
- **严重等级**: 致命（可能导致立案时当事人身份认定错误）
- **建议**: 统一为工商登记全称

**案例 2：旧日期残留**

> 原告浙江华诚律师事务所与被告杭州某某公司，因侵害商标权纠纷...
>
> 双方于2021年3月15日签订《商标许可使用合同》...

- **问题**: 本案为 2025 年新案件，但"2021年3月15日"未出现在任何当事人列表、案号或日期索引中作为关联日期
- **严重等级**: 严重
- **建议**: 核实是否为旧模板日期，修改为实际签约日期

## 误报控制

- 以下情况不算模板残留：
  - 历史日期是案件事实的组成部分（如"被告于2023年开始实施侵权行为"）
  - 同一当事人在不同位置使用简称与全称（简称是合法的指代方式）
  - 金额出现在证据清单中作为证据金额（非当事人主张金额）
- 置信度不足时，不输出问题，不标注为"疑似"
