# M5 法律术语/错别字

## 检查逻辑

1. 扫描全文，检测易混法律术语
2. 扫描全文，检测常见同音/形近错别字
3. 扫描全文，检测律师文书常见语病

## 信号模式

### 易混法律术语

| 错误用法 | 正确用法 | 说明 |
|---------|---------|------|
| 定金 | 订金 | "定金"有担保属性，"订金"仅为预付款，法律后果完全不同 |
| 法人 | 法定代表人 | "法人"是组织，"法定代表人"是自然人 |
| 抵押 | 质押 | 不动产抵押，动产和权利质押 |
| 罚金 | 违约金 | "罚金"是刑事处罚，民事中应为"违约金" |
| 专利权人 | 专利申请人 | 权利人可能不是申请人 |
| 肖像权 | 肖像 | "肖像权"是权利，"肖像"是客体 |
| 商标权 | 商标 | 类似区别 |
| 仲裁庭 | 仲裁委员会 | "仲裁庭"是审理组织，"仲裁委员会"是机构 |
| 法院 | 法庭 | "法院"是机构，"法庭"是审理场所 |
| 执行异议之诉 | 执行异议 | "执行异议"是程序行为，"执行异议之诉"是诉讼 |

### 常见错别字

| 错误 | 正确 | 场景 |
|------|------|------|
| 赔尝 | 赔偿 | 高频 |
| 委拖 | 委托 | 高频 |
| 起述 | 起诉 | 高频 |
| 侵权行为 | 侵害行为 | 部分场景下有区分 |
| 以上/以下 | 前款/后款 | 法条引用中混用 |
| 制定 | 订立 | 合同场景 |

### 常见语病

| 语病类型 | 示例 | 修改 |
|---------|------|------|
| 主谓不搭配 | "原告的证据证明了被告的侵权" | 检查主语和谓语是否匹配 |
| 指代不清 | "其向法院提起了诉讼" | "其"指代不明 |
| 句式杂糅 | "根据《专利法》规定第六十五条" | 应为"根据《专利法》第六十五条规定"或"根据《专利法》规定" |

## 典型案例

**案例 1：法律术语误用**

> 被告应向原告支付违约金100,000元。

- **问题**: 如果当事人确实约定的是"定金"（担保性质），则使用"定金罚则"处理；如实际为预付款，则应为"返还订金"。此处需要根据上下文判断术语使用是否准确
- **严重等级**: 严重（定金与订金法律后果完全不同）
- **建议**: 根据合同约定确认应使用"定金"还是"订金"

## 误报控制

- 以下情况不算错误：
  - 术语使用在该术语本身的有效场景中（如"违约金"在违约条款中使用）
  - 行业术语有争议用法且两种用法均有依据
  - 错别字是专有名词的一部分（如公司名中含有非标准字）
- 置信度不足的术语问题，标注为一般而非严重
