# M3 法条校验

## 检查逻辑

### 3a 格式校验（纯文本）

1. 从实体索引中提取所有法条引用
2. 检查格式规范性

### 3b 内容校验（法律法规库 MCP）

1. 从实体索引中提取所有法条引用
2. 逐一调用国家法律法规数据库 MCP 查询条文实际内容
3. 比对：文中对该法条的引用方式、描述是否与实际内容匹配

## 信号模式

### 3a 格式信号

| 信号 | 说明 | 严重等级 |
|------|------|---------|
| 法律名称不完整 | 如"专利法"应为"中华人民共和国专利法"或首次使用全称 | 一般 |
| 条文编号格式错误 | 如"第65条1款"应为"第六十五条第一款" | 严重 |
| 款/项表述错误 | "第一款"和"第一项"混用 | 严重 |
| 条文号不存在 | 如《专利法》只有82条，引用"第九十条" | 致命 |

### 3b 内容信号

| 信号 | 说明 | 严重等级 |
|------|------|---------|
| 文中描述的法条内容与实际条文不符 | 如引用"第六十五条"但描述的其实是"第六条"的内容 | 致命 |
| 文中引用的法条已被废止 | 条文已失效但仍被引用 | 致命 |
| 引用的法条存在但内容关联性弱 | 文中场景与条文适用范围不匹配（注意：只标注，不评价法律适用） | 严重 |

## 典型案例

**案例 1：条文号与内容不匹配**

> 根据《中华人民共和国专利法》第六十五条的规定，专利权的归属应当根据...

- **问题**: 《专利法》第六十五条是关于专利侵权赔偿数额的规定，而非专利权归属。专利权归属应为第十一条
- **依据**: 国家法律法规数据库
- **严重等级**: 致命
- **建议**: 核实应引用的法条，如指向权属应为第十一条

**案例 2：法律名称不规范**

> 依据专利法第七十一条之规定...

- **问题**: 未使用法律全称，首次引用时应为"《中华人民共和国专利法》第七十一条"
- **严重等级**: 一般
- **建议**: 首次引用使用全称

## 误报控制

- 以下情况不算错误：
  - 文中未直接引用条文内容，仅提及法条编号（无法比对内容）
  - 法律法规库 MCP 查询失败（网络或服务问题），跳过该条文的内容校验，仅做格式校验
  - 短语式引用（如"依据相关法律规定"），无法定位具体条文，不校验
- 内容校验的边界：
  - 只校验"条文内容是否被准确引用/描述"
  - 不评价"该条文是否适用于本案"
  - 不评价"法律适用是否正确"

## MCP 调用规范

- 使用国家法律法规数据库 MCP 搜索法条
- 每个法条引用最多调用一次
- 如单份文书中法条引用超过 10 处，仅校验关键法条（当事人主张核心权利所依赖的法条），其余仅做格式校验
