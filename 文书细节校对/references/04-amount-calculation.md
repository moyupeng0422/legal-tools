# M4 金额计算校验

## 检查逻辑

1. 从实体索引中提取所有金额
2. 识别金额间的计算关系：
   - 加总关系（本金 + 利息 + 违约金 = 合计）
   - 大小写对应关系
   - 单位换算关系（元 ↔ 万元）
   - 比例关系（持股比例、分成比例等）
3. 对有计算关系的金额组，调用 Python/Bash 执行精确计算
4. 比对计算结果与文书中数值

## 信号模式

| 信号 | 说明 | 严重等级 |
|------|------|---------|
| 分项加总不等于合计 | 如本金10万+利息2万≠合计11万 | 致命 |
| 大写与小写金额不对应 | "50000元" vs "伍万元整" | 严重 |
| 金额单位不一致 | 全文部分用"元"部分用"万元" | 严重 |
| 比例加总不为100% | 如甲方60%+乙方30%+丙方10%=100%则正确 | 严重 |
| 利息计算结果不正确 | 按文中给定的利率和期限计算，结果与文中不符 | 致命 |

## 典型案例

**案例 1：加总错误**

> 被告应赔偿原告经济损失共计人民币150,000元，其中：
> （1）本金损失100,000元；
> （2）利息损失20,000元；
> （3）维权合理开支35,000元。

- **问题**: 100,000 + 20,000 + 35,000 = 155,000，而非文书中的150,000
- **严重等级**: 致命
- **建议**: 核实分项金额或合计金额

**案例 2：大小写不对应**

> 被告应赔偿原告经济损失人民币壹拾万元整（100,000元）。

- **问题**: "壹拾万元"= 100,000，对应正确。但如果写成"壹拾万元整（10,000元）"则为错误
- **严重等级**: 严重（大写与小写不一致）
- **建议**: 核实并统一

## 误报控制

- 以下情况不做校验：
  - 金额出现在证据材料引用中（非当事人主张金额）
  - 金额表述为"约""大约""左右"等非精确数字
  - 无法确定计算关系的独立金额
- 利息计算的特殊处理：
  - 文中如未给出明确的利率和计算公式，不自行推算利息
  - 利息计算的起始日和截止日如不明确，标注"建议核实"而非直接判定错误
