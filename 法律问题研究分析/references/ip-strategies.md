# 知识产权案件专项检索策略

> 本文件为法律问题研究分析 Skill 的参考文件，按需加载。

## 专利侵权

法律问题研究分析中，专利侵权案件的核心在于理解权利要求范围、判断是否落入保护范围。检索时要注意：

- **法律依据**定位：专利法是基础，但司法解释和审查指南对等同原则、禁止反悔原则的解释同样关键
- **案例关注点**：等同侵权判定、禁止反悔原则适用、现有技术抗辩、合法来源抗辩
- **案例层次**：最高法指导性案例对等同侵权的认定标准是首要参考

```
法律依据：
  flk_search("专利法", range=1) → flk_get_detail → flk_hit_display("侵权")

典型案例：
  rmfyalk_search(keyword="专利侵权纠纷", case_sort="02")
  rmfyalk_search(keyword="等同侵权")
```

## 商标侵权

商标侵权的核心是混淆可能性判断。检索策略围绕商标近似、商品/服务类似、混淆可能性展开：

- **法律依据**：商标法 + 最高人民法院关于商标民事纠纷的司法解释
- **案例关注点**：混淆可能性判断标准、商标近似认定、驰名商标跨类保护
- **特别注意**：商标侵权与不正当竞争（如擅自使用知名商品特有名称）可能交叉

```
法律依据：
  flk_search("商标法", range=1) → flk_get_detail → flk_hit_display("侵权")

典型案例：
  rmfyalk_search(keyword="商标侵权", case_sort="02")
  rmfyalk_search(keyword="商标混淆")
```

## 著作权侵权

著作权侵权涉及作品认定、权利范围、侵权行为、抗辩事由多个层面。"实质性相似"是核心判断标准：

- **法律依据**：著作权法 + 信息网络传播权保护条例 + 计算机软件保护条例
- **案例关注点**：作品独创性认定、实质性相似判断、合理使用抗辩
- **特别注意**：不同类型作品（文字、美术、摄影、软件）的侵权认定标准有差异

```
法律依据：
  flk_search("著作权法", range=1) → flk_get_detail → flk_hit_display("侵权")

典型案例：
  rmfyalk_search(keyword="著作权侵权", case_sort="02")
```

## 商业秘密

商业秘密案件需要同时关注构成要件（秘密性、保密措施、商业价值）和侵权行为认定：

- **法律依据**：反不正当竞争法第 9 条 + 最高人民法院关于审理侵犯商业秘密民事案件的司法解释
- **案例关注点**：秘密性认定、保密措施合理性、客户名单保护、竞业限制交叉
- **特别注意**：商业秘密案件与劳动争议（竞业限制）常交叉，需注意举证责任分配

```
法律依据：
  flk_search("反不正当竞争法", range=1) → flk_hit_display("商业秘密")

典型案例：
  rmfyalk_search(keyword="商业秘密", case_sort="02")
```
