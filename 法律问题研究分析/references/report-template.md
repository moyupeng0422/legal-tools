# 研究报告输出模板

> 本文件为法律问题研究分析 Skill 的参考文件，Full 模式报告生成时加载。

## 使用说明

- `{{xxx}}` 为占位符，生成时替换为实际内容
- frontmatter 中的 tags/legal_areas 根据实际涉及领域填写
- 文件名格式：`法律研究-{{主题关键词}}-{{YYYYMMDD}}.md`
- **结论先行**：简要结论紧跟在研究问题之后，让读者第一时间获得答案
- **IRAC 框架**：综合分析中每个争议点按 Issue → Rule → Application → Conclusion 展开
- **案例深度**：每个案例必须分析法院的论理逻辑链条（裁判理由），不能只有要旨
