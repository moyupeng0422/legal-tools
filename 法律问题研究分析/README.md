# 法律问题研究分析 Skill

整合人民法院案例库、国家法律法规数据库两大 MCP，实现多源法律检索与综合分析。

## 功能特点

- **双模式检索**：Quick 模式快速查询，Full 模式完整五阶段研究流程
- **多源交叉校验**：法条原文 + 典型案例，形成完整法律论证链
- **知识产权专项**：内置专利/商标/著作权/商业秘密侵权分析策略
- **多格式输出**：支持 Obsidian 笔记、DOCX 研究报告

## 前置依赖

| 依赖 | 说明 |
|------|------|
| [人民法院案例库 MCP](../人民法院案例库MCP/) | 需配置 Token |
| [国家法律法规数据库 MCP](../国家法律法规数据库MCP/) | 无需认证 |

将上述 MCP 服务器配置到 Claude Code 的 MCP 设置中即可使用。

## 使用方法

将本文件夹中的 `SKILL.md` 放入 Claude Code 的 Skill 目录，或在项目中引用。详细操作流程和检索策略见 `SKILL.md`。

## 文件说明

| 文件/目录 | 说明 |
|-----------|------|
| `SKILL.md` | Skill 主文件，包含完整工作流程和检索策略 |
| `references/` | 参考文档（报告模板、IP 专项策略、输出格式等） |
| `scripts/` | 辅助脚本 |
