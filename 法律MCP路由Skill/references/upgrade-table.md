# 升级表（免费层 → 额度层）

> 作用：所有MCP调用的**升级路径依据**。原则：免费层（无限免费）失败才升级额度层；额度层内部按"免费额度→积分额度→稀缺额度"顺序，**付费/稀缺额度调用须用户确认**。
> 配套机制：止损规则（同工具≤2次，2次失败即停）· 预算守护（credit-dictionary.json 计费档位 + 额度池管理）
> 依据：2026-08-04 讨论定案 + 《五大法律MCP深度对比｜法律检索能力全维度实测（二）》实测结论
> **框架化定位（2026-08-21，2026-08-28 扩展）**：本文档 = **层级原则（固定）+ 已知9 MCP 深度知识（实测沉淀）+ 企查查企业数据事实桥**。用户实际升级路径按 `data/user-profile.json` 的 mcp_inventory 动态生成（见第四章框架化说明）；知识库外的 MCP 走通用模式——读 tool description 定参数，成本未知一律调用前确认。

## 一、计费速查（两层分级）

> 分层逻辑（用户定）：**免费层 = 无限制完全免费**；**额度层 = 一切有额度池的MCP**（无论免费赠送额度还是付费额度，都需预算守护管理）。

> **额度层内部优先级（2026-08-28更新）**：免费层（无限）→ **企查查法律数据/北大法宝/元典（定期积分或套餐额度）** → 法研（免费试用额度，限法规场景）→ 威科（**一次性稀缺，最后用**）。同层内按功能覆盖、单次档位与用户 `path_order_overrides` 排序。
> 关键：北大法宝/元典积分**定期补**，非稀缺资源，免费层能力不足时应优先用；威科10次**一次性**，用完即止，只留不可替代场景（语义最强/引用识别最完整）。付费/稀缺额度一律先经用户确认。

## 三、各功能升级路径

> 编号规则：按检索动作平铺（功能1-8），与案例检索、法条检索同构（精准/语义/综合三层）。

### 功能1 · 法条精准查询（已知法规名+条号；变体覆盖法规名+关键词）
> 2026-08-28 扩展：法信 → 企查查 → 元典 → 北大法宝 → 法研 → 威科
```
① 法信 law_search→law_detail          [免费层·首选：深度研究最优（关联法条/案例/释义/沿革/期刊）]
② 企查查 get_legal_article_detail/search [额度层·1分：条号直取或法规内关键词定位]
③ 元典 yuandian_rh_ft_detail          [额度层·赠送积分**1分**：法条详情极便宜]
④ 北大法宝 get_law_item_content       [额度层·赠送积分25分：元数据最丰富（⛔get_article已弃用，pitfall #17）]
⑤ 法研 flfg_iterative(title+item)      [额度层·免费试用500次内：目录定位+匹配评分]
⑥ 威科 search_law_article             [额度层·一次性稀缺10次内：款/项级精确，最后用，须确认]
```
> ⚠️ FLK 不用于确认完整法条（命中按段落），仅"确认法规是否存在/拿官方原文"时用（见功能7）；北大法宝禁用AGG聚合工具。
> 🔀 **变体路径（2026-08-27 立，法规名+关键词不知条号→先定位条号再回归主路径）**：
> ```
> ① 法信 law_search定gid→law_search_articles定位条文   [免费层·首选；通用短语空1次即升②（pitfall #34）]
> ② 企查查 get_legal_article_search                   [1分·法规名+关键词，固定最多20条]
> ③ 元典 rh_ft_search(keyword+fgmc)                   [5分·content即条文原文可直接引用]
> ④ FLK flk_search精确定bbbs→flk_hit_display           [免费层·返回命中片段非全文]
> ```

### 功能2 · 语义找法条（只有问题描述）
> 2026-08-28 扩展：沿用免费层定序，并在高价语义库前加入企查查3分原生语义：FLK → 法信 → **企查查 → 元典 → 北大法宝** → 威科
```
① FLK LLM拆词（high_search关键词）         [免费层·日常主力：把问题拆成法律概念词检索，效果不错]
② 法信 LLM拆词（law_search关键词）          [免费层·补充：拆词检索，结合关联资料扩展]
③ 企查查 get_legal_article_semantic_search [额度层·3分：原生语义，支持法规名/时效/效力/地域过滤]
④ 元典 yuandian_law_vector_search          [额度层·赠送积分15分：原生语义，效果与成本兼优（错别字容错实测有效，已知边界均有检测法——7种地方类必空/sxx只认现行有效/type混入须过滤，见f2卡）]
⑤ 北大法宝 search_article(+timeliness="现行有效") [额度层·赠送积分125分：语义效果存疑，且贵——④边界命中或④失败时补位]
⑥ 威科 search_law(question)                [额度层·一次性稀缺10次内：语义最强，**仅关键语义难题才用**，须确认]
```
> 💡 **调序依据（2026-08-26）**：旧序"北大法宝语义更强"被指南实测推翻（北大法宝指南自评"法规语义需优化、性价比存疑"；元典 15 分仅为 125 分的 1/8 且质量可控）——额度层原生语义**默认元典优先**，北大法宝降为补位
> ❌ **法研排除**：不用于语义找法条（无语义引擎，拆词检索效果差）
> ⚠️ FLK/法信非原生语义（LLM拆词）；企查查/元典/北大法宝/威科为原生语义路径

### 功能4 · 语义找案例（案情描述→候选案例）
> 2026-08-28 扩展：先免费层 LLM拆词，再用企查查3分结构化关键词检索；需要原生向量语义时仍按**元典(15分)先于北大法宝(125分)**，威科额度太少（10次），不到关键不用
```
① 法信 case检索（LLM拆词）                [免费层·日常主力：把案情描述拆成法律概念词检索]

③ 元典 case_vector_search(query)          [额度层·赠送积分15分：原生语义，完整语义query质量高，配套score锚点可质控]
④ 北大法宝 search_case(text)              [额度层·赠送积分125分：快速发现，深度研判须回get_case_list]
⑤ 威科 search_case(question)              [额度层·一次性稀缺10次内：**仅关键语义难题才用**，须确认]
```
> 💡 **调序依据（2026-08-26）**：同功能2——旧序"北大法宝语义更强"前提被指南实测推翻；元典 15 分 + score 锚点质控 + content AI提炼版可先筛，北大法宝 125 分降为补位
> ⚠️ **RMFYALK 不建议用于 LLM拆词语义检索**——正文不支持组合检索，拆出的多个关键词无法AND匹配，结果差/失效

### 功能5 · 类案检索（裁判文书+类案研判）

① 法信 case检索（案由+关键词+法院+审级+年份等20+维度） [免费层·条件最全，首选]

### 功能6 · 权威案例（指导性/参考案例）
> 2026-08-28 扩展：保留“元典先于北大法宝”的既有定序，在 RMFYALK 后前插企查查3分权威案例检索。

## 四、检索使用规则（按任务类型，用户2026-08-04重构）

> 核心原则：**升级链是"故障驱动"（失败了才升），使用规则是"任务性质驱动"**——先判断任务类型，再决定调用策略。
> **框架化说明（2026-08-28）**：第三节各功能升级路径中的 MCP 顺序是**已知9 MCP 知识库的默认排序**；实际执行时按 `data/user-profile.json` 的 mcp_inventory 动态生效——路径中 profile 未启用/不在线的 MCP 自动跳过；profile.path_order_overrides 非空时按覆盖序执行（仅调序，收费确认/AGG禁用等红线不豁免，见 onboarding-guide 附录）；**层级原则固定不变**：free（无限）→ quota_recurring（定期赠送积分）→ free_trial（免费试用）→ one_time（一次性稀缺）。

### 4.0 功能覆盖度兜底（框架化必读）

> 场景编排按序执行；**某功能在当前 profile 的 MCP 清单中无任何工具可对应时，明确标注"本 profile 未覆盖功能N"并继续后续功能**，不得硬凑其他功能冒充、不得静默跳过（防编造红线延伸）。典型情形：用户只有 FLK 单 MCP 时，功能5类案检索（需案例库）无对应工具 → 标注"未覆盖功能5"后跳到功能7时效核验。

### 4.1 两类检索任务

| 类型 | 目标 | 成功标准 | 涉及功能 |
|---|---|---|---|
| **确定型**（找到即止） | 唯一确定答案（法条原文/案号案例） | **命中且可信 = 完成**，不重复验证 | 功能1法条精准 / 功能3精准找案例 / 功能6权威案例 / 功能7时效核验 / 功能8引用校验 |
| **分析型**（多源互补） | 全面候选+交叉印证（语义找法/类案研判） | 多源互补/校验后的**结论** = 完成 | 功能2语义找法条 / 功能4语义找案例 / 功能5类案检索 / 功能9法条关联资料 |

### 4.2 确定型检索使用规则（找到即止）

```
① 按该功能的升级路径顺序调用（功能1路径见第三节）
② 一旦命中且结果可信（来源权威 + 时效有效）→ 立即停止，不升级、不重复验证
③ 仅当失败（400/空结果/异常）或结果存疑（来源不可靠/时效不明）→ 才按4.4升级触发切换
```

> **⚠️ 路径优先级（2026-08-27 立，总skill 红线第7条同源）**：**功能升级路径以本表第三节/速查卡定序为唯一依据**；"层级免费优先"原则仅作路径内排序参考，**路径外工具（含免费工具）不得因"免费"擅自引入**——路径内全灭或存疑需换路径外工具时，须上报主agent 批准（abtest-F1-20260827 A1 教训：法信空结果后子agent 自行引入路径外 FLK 并自评合规）。
> **子skill 覆盖约定优先（2026-08-27 立）**：子skill 在其 SKILL.md"覆盖约定声明"节显式约定与本规则不同的（如 F1 的 F1.2/F1.3 关键结论≥2源交叉验证），**从其约定**——子agent 提交方案时列出差异点，主agent 审核按覆盖约定优先放行（红线/预算硬约束不可覆盖）。

### 4.3 分析型检索使用规则（多源互补 + 分级投入）

```
① 免费层（无限免费）：能用几个用几个（法信+FLK+RMFYALK）
   - 目的：数据互补（不同库覆盖不同）+ 交叉校验（同结论多源印证防幻觉）
② 额度层：至少用1个
   - 法研（免费试用500次）：仅法规场景可先用于免费试用额度（不花积分）
   - 北大法宝/元典（赠送积分）：提供关键词/语义维度补充（免费层无语义引擎）
③ 整体评估：汇总多源结果，确认覆盖度/一致性是否满足需求
④ 不足再补：评估后发现仍有缺口（如没找到关键类案/赔偿标准）
   → 再评估是否引入额外额度层（更高费用档），不一次全上
```

### 4.4 升级触发规则（故障/资源兜底，非日常路径）

| 情形 | 动作 |
|---|---|
| 免费层调用失败（400/空结果/异常） | 按止损处理（≤2次）→ 仍失败则升级额度层 |
| 额度层·赠送积分（北大法宝/元典）调用失败/耗尽 | **优先于法研/威科**：积分定期补，等补或换同层其他工具 |
| 额度层·免费试用（法研）调用失败/耗尽 | **法研能力弱（仅法规）作兜底**：法规精确检索场景可降级用法研；非法规场景直接升级 |
| 一次性稀缺（威科10次） | **最后启用**，只留不可替代场景（语义最强/引用识别最完整），须确认 |
| 付费/稀缺额度调用 | 一律先经用户确认（预算守护：额度池余额+单次/累计阈值） |
| 免费层/赠送积分结果已满足需求 | **禁止升级**（不花冤枉钱） |
