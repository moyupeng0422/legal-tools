# 功能1 · 法条精准查询（已知法规名+条号；变体覆盖法规名+关键词）

> ⚡ **轻量快答选读导引**：快答（F1.1/态①②）通常仅需本卡头部 + ①②段（+🔀变体段/🔁交叉段按需），③-2 为弃用工具历史备忘、③④⑤为升级备选——按需选读，无需整读。

> ⚠️ **调用包裹格式（本卡涉及：法信=包裹 / 企查查·元典·北大法宝·法研·威科=平铺）**：法信侧工具（faxin_law_*）参数须包一层 `{"params": {...}}`；企查查/元典/北大法宝/法研/威科侧参数**平铺直传**，不包 params。企查查完整参数见 `qcc-legal.md`。

> 升级路径（2026-08-28 扩展）：**法信 → 企查查 article_detail/article_search(1分) → 元典(1分) → 北大法宝(25分) → 法研(免费试用) → 威科(10次)**
> **企查查指针**：已知法规名+条号用 `get_legal_article_detail(regulationName, articleNo[, referDate])`；法规名+关键词用 `get_legal_article_search(keyword, regulationName)`。搜索返回 opaque id 后可原样下钻详情；不得猜 id/分页参数。完整表见 `qcc-legal.md`。
> ⚡ **条件化例外·三态明示（2026-08-27 实测后立，同日快答提速扩为三态）**——快答/F1.1 按任务形态对号入座，**每态工具可用性以 profile `mcp_inventory` 实际启用为准**（`speed_mode` 覆盖键见 lightweight-protocol §二能力槽位段；未启用即回落法信免费路径，均属路径内不越权）：
> - **态① 条号已知（用户明示，或执行者凭知识可定位——后者直取后必须核对条旨/内容，见本行⚠️）** → **条号直取型单发工具**：本库低成本同档 = 企查查 `get_legal_article_detail`（1分）/ 元典② rh_ft_detail（1分），均可一次到位；同型可选：法研④免费试用 / 北大法宝③ get_law_item_content（25分）——按 profile 启用态、预算与来源需求择优。⚠️ **执行者凭知识推理出条号即属本态，直接直取，勿先走检索路径**（2026-08-28 快答对照测试实证：已推理出条号仍先 fgmc 检索→命中非法典文档跑偏，多花 1 轮 +5 分 ≈40s；直取后按返回原文核验即合规）；**且核对条旨/内容与问题匹配，非仅条号一致**——大修法规条号迁移时，条号核对仍可能拿到目标条号的现行无关内容；**结论标注款号时必须对照返回原文逐款定位，禁止凭记忆标注款号**。
> - **态② 无条号·速度优先** → **单发检索工具**：优先企查查 `get_legal_article_search`（1分，固定最多20条），不可用/不命中再用元典变② rh_ft_search（5分，content 即条文原文，详见 🔀 变体段）；新修法规可能存在收录延迟，空即回落法信免费路径勿重试
> - **态③ 书面来源/官方权威标注需求** → 免费两步（法信① 定 gid→条文，返回带时效字段适合正式引用场景）
>   三态共同前提另见 pitfall #34 大法典预判规则；法信起手的价值在免费+时效字段，仍适用于态③与非快答场景
> 类型：**确定型**——命中且可信即停止，不重复验证（升级表4.2）
> 坑位：见 pitfall-checklist #13/#17（条号格式、get_article贵5倍；原 #14 条号格式混淆已并入 #17 备注——get_article 已弃用）
> ⚠️ **FLK 不在功能1 主路径**（已知条号直取，有意排除）：`flk_search`/`flk_hit_display` 定位粒度粗（返回命中片段、无法高亮定位到条内款项目），且 `flk_search` 模糊模式跑偏（模糊搜"民法典"曾返回宪法；须 `search_type=1` 精确 + title 完整法规名，工具详情见 f7 卡）——主路径按本卡①~⑤执行，**路径内全灭时经主agent 批准**可作免费兜底（总skill 红线第7条）；**变体场景（法规名+关键词不知条号）**中 flk 组合为合法候选之一（见文末 🔀 变体段）
> ⚠️ **法信 Cookie 过期处置（2026-08-26 MCP 工具层修复后）**：检索报"Cookie 已过期"或返回"⚠️ Cookie 疑似过期"（空结果可能为过期态表现，pitfall #43）→ **直接调 `faxin_laws_auto_login` 工具自助刷新**（本卡法信工具均属法规侧 laws server，实测 L2 登录约 39s，成功自动同步凭证），刷新后重试本检索；工具刷新失败才按降级规则"标注缺失继续"并上报总skill

## ② 元典（额度层·**1分**·赠送积分）

### yuandian_rh_ft_detail — 法条详情（性价比之王）
| 参数 | 必填 | 说明 | 示例 |
|---|---|---|---|
| fgmc + ftnum | 二选一* | 法规名称 + 法条号（**中文**格式） | fgmc="民法典", ftnum="第五百七十七条" |
| id | 二选一* | 法条ID（经检索获得，**优先级最高**——全字段同传时只按 id 返回） | — |
| refer_date | 否 | 历史版本参考日期(yyyy-MM-dd) | — |

> *id 与 (fgmc+ftnum) 至少传一组。ftnum 三格式全兼容：中文"第八十七条" / 数字"87" / 带小数点"133.1"=第一百三十三条之一（内部 tid 机制）。
> 💡 **检索定位后引用无需下钻本工具**（2026-08-17 指南实测）：rh_ft_search（5分，f2卡）的 **content 已是完整条文原文**（与⑤逐字一致）——"检索定位→引用"路径用②即可；⑤仅用于"已知法规名+确切条号直取"（1分）及 refer_date 历史版本
> ⚠️ **实测坑位（2026-08-15，pitfall #35/#36）**：
> - **fgmc 版本后缀陷阱**：带"(2012修正)"等后缀会静默误匹配旧版——**查现行=通用名不带后缀；查历史=通用名+refer_date；绝不传版本后缀**；返回后核对 fwzh/sxx/fgmc
> - **"之一"不存在时静默回退母条**（不报错）——**必须核对返回 ft_num == 请求条号**，不一致即弃用
> - **refer_date 条号错位**：不同版本条号未必一一对应（大修法规尤甚）——历史版本确认**优先用④rh_fg_detail 整法级**（按【条旨】定位无此问题），确需⑤先确认历史版确切条号
> - 不存在（fgmc/条号/id任一）→ **code=200 静默空返回**——**200≠查到，必须检查 message/data**（⚠️空结果文案因工具而异：②③="未查询到相关**数据**"；④⑤⑦⑧⑨="未查询到相关**内容**"，按文案判空须区分）

## 🔀 变体：法规名+关键词找条（不知条号）

> 场景："商标法里驰名商标保护是怎么规定的？"——有明确法规目标但不知条号；不满足主路径前提（要条号），也非功能2语义找法条（那边没有法规目标）
> 变体升级路径（2026-08-28 扩展）：**法信(免费) → 企查查 article_search(1分) → 元典(5分) → FLK(免费兜底)**
> 引用纪律：变体只负责**定位条号/条旨**，拿到后回归主路径取全文核验再引用（①law_detail 免费 / ②rh_ft_detail 仅1分），不在定位步直接下结论
> 兜底：法研 flfg_iterative(query.title + query.content "某法主题") 组合（免费试用内，工具见主路径④）

### 变① 法信 · 免费层首选（复用主路径①工具，参数表见上）
组合用法：faxin_law_search(key_title="商标法"，search_mode="标题精确") 定 gid → faxin_law_search_articles(gid, keyword="驰名商标") 定位具体条文

> ⚠️ 法规体量决定成败（pitfall #34，2026-08-27 裁决）：目标为大法典（民法典级）时**预判跳过本组合、直接升变Q企查查；不可用再升变②元典**；中小法典正常可用；空/超时≤2次即停勿换词重试

### 变Q 企查查 · 额度层1分

`get_legal_article_search(keyword="驰名商标", regulationName="中华人民共和国商标法")`。参数平铺，固定最多20条，命中项已含条文正文，核对法规名/条号/时效后可直接引用；仅在需要单条规范化详情时，才将“法条ID”原样传 `get_legal_article_detail(id)`（另计1分）。完整参数与坑位见 `qcc-legal.md`。

### 变② 元典 · 额度层5分 · content 即原文可直接引用
rh_ft_search(keyword="驰名商标", fgmc="商标法") —— 完整参数表与坑位见 **f2 卡④-2**（该工具主卡），本变体两点关键差异：

> - **fgmc 必传**（锁定目标法规，否则跨库散检）；fgmc 空格=AND，与 sxx/dy/fbbm 空格=OR 规则不同（f2 卡④-2 坑）
> - content 返回条文原文，**本变体唯一"定位即得原文"的路径**——无需回归主路径下钻
> 另：rh_ft_search 全时效可用（"失效"可查），是语义检索（功能2③④）必空时的正确替代（f2 卡④坑）——**查已失效条文时变②仍适用**；但历史版本整法核对仍以 f7 卡④rh_fg_detail 为先

### 变③ FLK · 免费层兜底（两步：定 bbbs → 命中片段）
第一步 flk_search(search_type=**1精确**，search_content=完整法规名) 定 bbbs（模糊模式跑偏坑见 f7 卡）；第二步在该法规内命中条文片段：

#### flk_hit_display — 法规内关键词命中条文片段
| 参数 | 必填 | 说明 | 示例 |
|---|---|---|---|
| bbbs | ✅ | 法规ID（上一步 flk_search 获取） | "ff8081817ab231eb..." |
| search_content | ✅ | 检索关键词（1-200字符），与定位时用词一致 | "驰名商标" |
| search_type | 否 | 1=精确 / 2=模糊（默认2） | 2 |
| search_range | 否 | 1=标题（默认）/ 2=全文（**命中条文用2**） | 2 |

> ⚠️ 返回为关键词所在条款的**片段截取**（含前后上下文，关键词加粗），非完整条文——长条文/多款须 flk_get_detail 或 flk_download 取全文
> 多条件组合过滤改走 `flk_high_search` → `flk_high_hit_display(bbbs + 相同conditions)`（两步约束：必须传与搜索时完全相同的 conditions 列表）

### 排除与绕行（依据调研报告实测）

> - **北大法宝无条文级关键词工具**：get_law_list(title/fulltext, 25分) 只到法规级元数据——"关键词→条文"的正确路径是语义 search_article（125分，f2 卡④），**不为省25分绕道125分**；批复/司法解释类文件仍走 get_law_list 定位（见 f7 卡）
> - **威科 search_law_keyword 为法规级关键词检索**（空格分割词→返回法规列表，不到条文级，参数表见 f7 卡⑥）——用于本变体多花一步且耗10次稀缺额度，不推荐

## 🔁 交叉验证段（关键结论 ≥2 源，2026-08-27 立；同日复测后补降档与范围口径）

法条属"关键结论"（决定答复方向）的场景（如 F1.2/F1.3 覆盖约定），路径命中后须交叉验证：
- **范围**：**最核心 1-2 条法条**（决定答复方向者），非逐条全交叉（retest-C2 主agent 裁量制度化）
- **降档原则（先免费后额度）**：交叉源选择与主源互补、就低不就高——
  - 主源为免费层（法信①）→ 交叉用元典② `rh_ft_detail`（1分）
  - 主源为额度层（企查查/元典②/北大法宝③）→ 交叉**优先免费源**（法信① law_detail 整部全文核对条文原文）；免费源不可用/不覆盖才用另一额度源
- fgmc 用通用名不带版本后缀，返回后核对 ft_num 与请求条号一致
- **边界**：交叉验证与"确定型即停"不矛盾——即停=不重复检索**同源**；交叉=换**独立数据源**验证（upgrade-table 4.2 覆盖约定声明）
- F1.1 等轻量场景默认单源+来源标注，结果存疑才交叉（F1 子skill 覆盖约定 #1）
