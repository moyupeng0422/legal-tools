## ① 防幻觉判定（核心·当前降级）——⚠️ hall_detect 默认关闭，按需启用

> ⚠️⚠️ **hall_detect 为元典会员专属接口，当前账号非 VIP 不可用**（2026-08-13块G实测 HTTP 403"该接口只有VIP用户才能访问"，50分未扣，pitfall #33）。
> **默认状态：关闭**——防幻觉判定一律走 ②一般检索核验（功能1/3，免费~25分）：法条用功能1查证原文、案号用功能3查证真实。
> **启用条件（按用户实际情况决定）**：①账号已升级元典 VIP ②任务为关键结论校验（意见书/正式交付物）且用户明确同意花50分——两条件同时满足才走本工具；启用前先在 `scripts/.env` 填入 YUANDIAN_API_KEY（2026-08-20 已清空防泄露）。

## ② 其他校验 → 回归一般检索（省钱方案）

| 校验需求 | 回归路径 | 成本 |
|---|---|---|
| 验证某法条存在/原文 | **功能1**（法信/元典1分/北大法宝25分） | 免费~25分 |
| 验证案号真实 | **功能3**（RMFYALK case_ref/法信case_id） | 免费 |
| 验证案例标题/来源 | **功能5/6**（法信/北大法宝get_case_list） | 免费~25分 |
| 法规引用有效（《法》名+条号+失效标注） | 功能1 + 功能7时效核验 | 免费 |
| **疑"某判例是否真援引某法条"** | **元典⑧ yyft 反查（独有能力，2026-08-17 指南）**：`rh_ptal_search {"yyft":["中华人民共和国专利法第六十五条"]}` → **total>0 即该法条被引用过**（total=24671）；命中后拿 id → ⑨rh_case_details 核对"本院认为"援引原文 | 5~15分 |

> ⚠️ 若确需威科 legal_citation（10次稀缺内）：**法规名必须带《》书名号**（pitfall #12），否则识别失败白调一次

> 原理：引用校验的本质是"查证存在性"——用**确定型检索**（功能1/3）就够，不需要贵价识别类工具（CC审核v3认可此设计）

## ③ 输出审核三维度（主agent事后审核标准）

> 子agent输出检索报告后，主agent按此审核（衔接协议⑨），不达标发回补正≤2次：

| 维度 | 要求 |
|---|---|
| 来源清晰 | 每条引用标注来源（MCP+工具+时间） |
| 可追溯回查 | 法条给"法规名+条号+URL锚点"；案例给"案号+法院+日期+URL" |
| 已校验 | 关键法条过hall_detect；案号过功能3查证 |
| 时效标注 | 法条标"现行有效/已修改"；案例标裁判日期 |
| 防编造 | 空结果≠无数据，禁止编造"不存在/无此类规定" |
