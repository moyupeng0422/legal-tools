## 轻量 5 步

```
① 判层确认（主agent）：按本文件头部判层线索确认 F1.1（判断不唯一取更深 → 转标准分发）
② 检索 1-2 次命中即停（主agent）：
   · 功能1（法条精准）+ 功能7（时效核验）
   · 工具与定序按 f1 速查卡（../../references/parameter-cards/f1-law-exact.md）/ upgrade-table 路径执行，
     本层不写死 MCP 选择
   · 简单时效问答（"X多久"）由功能1条文原文直接承载；**仅涉版本沿革/修订历史对比时才读 f7 卡**（2026-08-27 快答提速固化）
   · 空 1 次即按路径升级，勿同工具换词重试（pitfall #34：空或超时同理）
   · 检索超 2 次仍未命中 → 转标准分发（见下）
③ 三要素快答模板输出 + 来源标注
④ log_usage 记账（每次调用后，不豁免）
⑤ 简版管控报告（3 行：路由/调用/消耗）
```

## 输出模板（对话内快答，不落文件）

```
结论：___
依据：《___》第___条（来源：___·现行有效/已修改）
补充提示：___
```

> 所有引用满足：来源清晰（哪个MCP哪个工具）+ 可追溯回查（条号）+ 已校验（法条真实存在，来自检索结果非记忆）。

## 交叉验证（覆盖约定 #1 的 F1.1 口径）

默认单源+来源标注即可；**结果存疑时**（法条内容与常识不符/版本存疑/检索结果互相矛盾）才交叉验证——按 f1 卡交叉段（`../../references/parameter-cards/f1-law-exact.md` 交叉验证段）交叉 1 次，存疑点在快答"补充提示"中如实说明。

## 转标准分发触发（立即切换，不硬撑）

- 判层线索不命中：客户带具体案号 / 意见书关键词（"出具意见""书面意见""正式答复"）/ 跨领域 / 陌生领域需搭框架 / 多法条多焦点；
- 检索结果与预期不符（关键法条查不到/内容矛盾）；
- 检索需求超出 1-2 次（需多法条组合分析）。

转标准分发后：读子skill 骨架判层重新定层（通常是 F1.2），Agent 工具启动子agent，从方案设计环节接续（子agent 读 `layers/f1-2-memo.md` 执行）。
