## 专利侵权

法律问题研究分析中，专利侵权案件的核心在于理解权利要求范围、判断是否落入保护范围。检索时要注意：

- **法律依据**定位：专利法是基础，但司法解释和审查指南对等同原则、禁止反悔原则的解释同样关键
- **裁判规则**关注点：等同侵权判定、禁止反悔原则适用、现有技术抗辩、合法来源抗辩
- **案例层次**：最高法指导性案例对等同侵权的认定标准是首要参考

```
法律依据（功能1 + 功能2 + 功能7）：
  功能1：检索词 "专利法"（标题精确）→ 命中法条提取关键词 "侵权"
  功能1/2 补充法规：检索词 "专利"（国家法律库+法信法规库）

裁判规则（功能5，并行多组检索词）：
  检索词组："专利侵权"（总览）
            "等同侵权"（等同原则）
            "禁止反悔"（禁止反悔原则）
            "现有技术抗辩"（抗辩事由）

典型案例（功能6，并行）：
  检索词组："专利侵权纠纷" / "等同侵权"
```

## 商标侵权

商标侵权的核心是混淆可能性判断。检索策略围绕商标近似、商品/服务类似、混淆可能性展开：

- **法律依据**：商标法 + 最高人民法院关于商标民事纠纷的司法解释
- **裁判规则**：混淆可能性判断标准、商标近似认定、驰名商标跨类保护
- **特别注意**：商标侵权与不正当竞争（如擅自使用知名商品特有名称）可能交叉

```
法律依据（功能1 + 功能2 + 功能7）：
  功能1：检索词 "商标法"（标题精确）→ 命中法条提取关键词 "侵权"
  功能1/2 补充法规：检索词 "商标"（国家法律库+法信法规库）

裁判规则（功能5，并行多组检索词）：
  检索词组："商标侵权"（总览）
            "混淆可能性"
            "商标近似"
            "驰名商标"

典型案例（功能6，并行）：
  检索词组："商标侵权" / "商标混淆"
```

## 著作权侵权

著作权侵权涉及作品认定、权利范围、侵权行为、抗辩事由多个层面。"实质性相似"是核心判断标准：

- **法律依据**：著作权法 + 信息网络传播权保护条例 + 计算机软件保护条例
- **裁判规则**：作品独创性认定、实质性相似判断、合理使用抗辩
- **特别注意**：不同类型作品（文字、美术、摄影、软件）的侵权认定标准有差异

```
法律依据（功能1 + 功能2 + 功能7）：
  功能1：检索词 "著作权法"（标题精确）→ 命中法条提取关键词 "侵权"
  功能1/2 补充法规：检索词 "著作权"（国家法律库+法信法规库）

裁判规则（功能5，并行多组检索词）：
  检索词组："著作权侵权"（总览）
```

## 商业秘密

商业秘密案件需要同时关注构成要件（秘密性、保密措施、商业价值）和侵权行为认定：

- **法律依据**：反不正当竞争法第 9 条 + 最高人民法院关于审理侵犯商业秘密民事案件的司法解释
- **裁判规则**：秘密性认定、保密措施合理性、客户名单保护、竞业限制交叉
- **特别注意**：商业秘密案件与劳动争议（竞业限制）常交叉，需注意举证责任分配

```
法律依据（功能1 + 功能2 + 功能7）：
  功能1：检索词 "反不正当竞争法"（标题精确）→ 命中法条提取关键词 "商业秘密"（定位第9条）
  功能1/2 补充法规：检索词 "商业秘密"（国家法律库+法信法规库）

裁判规则（功能5，并行多组检索词）：
  检索词组："商业秘密"（总览）
            "保密措施"
            "客户名单"
            "竞业限制 商业秘密"

典型案例（功能6，并行）：
  检索词组："商业秘密"
```
