# 引用来源 URL 构造与链接放置规范

> 本文件为 F1 咨询子skill 的参考文件，Phase 5 报告生成时加载。源自原「法律问题研究分析」skill 的 CLAUDE.local.md（2026-06-17 沉淀），2026-08-26 随融合合并随迁为 skill 运行时资产。

## URL 构造规则（免费层 3 库）

| 数据源 | 详情页 URL 格式 |
|--------|---------------|
| 国家法律法规数据库（FLK） | `https://flk.npc.gov.cn/detail?id={bbbs}` |
| 人民法院案例库（RMFYALK） | `https://rmfyalk.court.gov.cn/view/content.html?id={cpws_al_id}&lib=ck` |
| 法信裁判规则 | `https://sfb-vip.faxin.cn/lib/cpal/AlyzContent.aspx?isAlyz=1&gid={gid}&libid={libid}` |

> 占位符取值均来自检索结果返回的对应字段（bbbs / cpws_al_id / gid+libid），不凭记忆或猜测填写。

## 7-MCP 适配规则（合并新增）

- 以上 URL 构造规则**仅覆盖免费层 3 库**（FLK/RMFYALK/法信）
- 额度层 MCP（北大法宝/元典/威科）的详情链接**以检索结果返回的链接字段为准，禁止自行构造**；返回结果无链接字段时，来源数据库列标注 MCP 名称，详情链接列留空（不编造）

## 链接放置规则

1. **链接统一放在「详情链接」列**，名称列不加链接（纯文本）
2. **每个案例/法规只标注实际检索到的数据来源**，未检索到的数据库不要标注
3. **案例只在能检索到的数据库中提供链接**，未收录的库不要编造链接

> **反面案例**（2026-06-17 实际踩坑）：对"李某诉刘某"案例同时标注法信 + 人民法院案例库并都加了链接，但该案例实际只收录在法信中。编造的链接打开后显示错误案例。

> **链接说明**：国家法律法规数据库链接为公开访问；法信和人民法院案例库链接需登录后才能查看详情页。
